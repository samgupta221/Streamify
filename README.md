# 🎧 Streamify – Language Exchange Platform

Streamify is a **real-time language exchange platform** that helps users connect with people around the world to practice and learn new languages through live chat and social interactions.

---

## 🚀 Features

* 🔐 **User Authentication** (Secure login & signup)
* 👥 **Friend Management** (Send & accept friend requests)
* 💬 **Real-time Chat** using Stream API
* 🌍 **Language-based Matching** (Native & learning languages)
* 🔔 **Notifications** for messages and requests
* 🌙 **Modern Dark UI** with responsive design

## 🧠 How It Works

* Users register and set their **native** and **learning languages**
* The system recommends language partners
* Users can send **friend requests**
* Once connected, users can chat in **real time** using Stream API
* JWT ensures secure access to protected routes
